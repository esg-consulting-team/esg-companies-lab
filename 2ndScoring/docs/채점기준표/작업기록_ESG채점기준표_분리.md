| 파일 | 대상 | 항목 수 |

## 2. 시트별 처리

- **01_ESG통합진단마스터**, **02_점수산정참고표**: 분류코드 접두어(E/S/G/P/반도체) 기준으로 행만 필터링해서 복사. 헤더 색상·열 너비·틀고정 등 원본 서식 그대로 유지.
- **03_지배구조세부점검(KRX)**: 지배구조(G) 전용 시트라 **G 파일에만** 포함 (E, S 파일에는 없음).
- **04_KSSB갭분석**: 완전대응/부분대응/GAP 건수·항목수 합계·완전대응율을 각 파일 기준으로 재계산.
  - G 파일은 정보공시(P) / 지배구조(G, 반도체특화 제외) / 업종특화(반도체) 3개 행으로 세분화.
- **05_요약대시보드**: 전체 진단항목 수, 점수입력 완료율, 영역별 평균점수, 적용구분별(기본/추가/업종특화) 항목 수 재계산.

## 3. 수식 복원 (2차 작업)

1차로는 04/05 시트를 파이썬으로 계산한 고정값으로 채웠으나, "작업자 편의성을 살려달라"는 요청에 따라 원본처럼 **01시트 입력값에 실시간 연동되는 엑셀 수식**으로 재작업함.

- `COUNTIFS` / `AVERAGEIFS` / `SUMPRODUCT` / `IFERROR` 조합으로, 각 파일의 01시트 데이터 범위(`$D$3:$D$29` 등, 파일마다 행 수가 달라 범위 다름)를 참조.
- G 파일의 "지배구조" 집계는 반도체특화 항목을 이중 계산하지 않도록 `<>업종특화(반도체 v1.0)` 조건으로 제외 처리.
- 즉, 각 담당자가 01시트에 `[입력]충족단계/요건수`나 `자사취득점수`, `KSSB 대응현황` 등을 채우면 04/05 시트가 자동으로 갱신됨.

### 검증
- `formulas` 라이브러리로 실제 엑셀 수식을 재계산해 값 확인.
- E(완전대응 5, GAP 10) + S(완전대응 0, GAP 29) + G(완전대응 3, GAP 13) = 완전대응 8, GAP 52 → 원본 전체 수치와 정확히 일치.
