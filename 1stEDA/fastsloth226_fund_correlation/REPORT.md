# 작업 보고서: fastsloth226_fund_correlation

담당: FastSloth226
파일: `eda_kospi_index.ipynb`

## 1. 개요

README에 명시된 가설은 "ESG펀드 보유종목 구성에서 상관관계가 큰 변수 탐색"이지만,
실제 노트북에서 진행된 작업은 **KRX ESG지수와 코스피(KOSPI200) 지수 간의 추세·상관관계 비교**다.
가설과 실제 분석 내용이 다르므로, README 업데이트가 필요하다.

## 2. 데이터 및 수집 방법

- **출처**: KRX 정보데이터시스템 Open API (`data-dbg.krx.co.kr`)
  - `esg_index_info`: ESG지수 일별 시세
  - `kospi_dd_trd`: 코스피 지수 일별 시세
- **수집 기간**: 2023-01-01 ~ 2025-12-31 (영업일 기준 약 783일)
- **수집 방식**: 날짜별로 API를 반복 호출(loop)해 일별 시세를 누적 수집, `pandas.concat`으로 병합

## 3. 분석 내용

1. 단일 날짜 조회로 API 응답 구조 확인 (`OutBlock_1`)
2. 3개년 전체 영업일에 대해 ESG지수·코스피200 지수를 순차 수집
3. 문자열로 내려오는 종가(콤마 포함)를 숫자형으로 변환
4. 날짜 기준으로 두 지수를 join하여 병합 데이터프레임 구성
5. `statsmodels`를 이용한 회귀분석으로 ESG지수 vs 코스피200 관계 검증 준비

## 4. 진행 상태

- 코드 실행까지는 진행되었으나, **회귀분석 결과 및 결론 부분은 노트북에 아직 출력/정리되어 있지 않음**
- README의 "검증 방법", "검증 결과" 항목도 미작성 상태
