# 1stEDA

`esg-hypothesis-lab/hypotheses`에서 가져온 팀원별 1차 가설 검증(EDA) 작업 모음.

## 폴더 구성

| 폴더 | 담당 | 내용 |
|---|---|---|
| [`fastsloth226_fund_correlation`](fastsloth226_fund_correlation/) | FastSloth226 | ESG지수 vs 코스피 지수 상관관계 탐색 |
| [`hyc6028_esg_env_impact`](hyc6028_esg_env_impact/) | hyc6028 | ESG등급과 실제 온실가스 배출량 간 관계 탐색 |
| [`jiye1211_tbd`](jiye1211_tbd/) | jiye1211 | 업종별 E/S 중심도 차이, ESG점수-주가 하방리스크 검증 |
| [`minjukim22_esg_weight`](minjukim22_esg_weight/) | MinjuKim22 | E·S·G 개별점수의 통합등급 반영 가중치 추정 |

각 폴더에는 다음 두 문서가 있다.

- `README.md`: 담당자가 작성한 가설/데이터/검증 방법 정의서 (원본)
- `REPORT.md`: 노트북·데이터 파일을 확인해 정리한 진행 상황 보고서

전체 4개 폴더의 진행 상황을 한 번에 보려면 [`작업현황.md`](작업현황.md)를 참고.
